## 2. Complete SQL Setup (Run once in Supabase SQL Editor)
Run this SQL script in your [Supabase Dashboard > SQL Editor](https://supabase.com/dashboard/project/kiwpzxjdbcwkfafngdgj/sql) to enable full read, write, update, and cancellation capabilities for the Admin Panel:

```sql
-- 1. Create bookings table with room allocation and caretaker notes
CREATE TABLE IF NOT EXISTS bookings (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  full_name TEXT NOT NULL,
  phone TEXT NOT NULL,
  section TEXT NOT NULL,
  sharing_type TEXT NOT NULL,
  move_in_date DATE,
  message TEXT,
  status TEXT DEFAULT 'pending',
  assigned_room TEXT,
  notes TEXT
);

-- 2. Enable Row Level Security (RLS)
ALTER TABLE bookings ENABLE ROW LEVEL SECURITY;

-- 3. Allow public visitors to submit booking appointments
CREATE POLICY "Allow public insert on bookings" ON bookings
  FOR INSERT TO anon, authenticated
  WITH CHECK (true);

-- 4. Allow admin panel to read all bookings
CREATE POLICY "Allow public select on bookings" ON bookings
  FOR SELECT TO anon, authenticated
  USING (true);

-- 5. Allow admin panel to update status, assign rooms, and edit notes
CREATE POLICY "Allow public update on bookings" ON bookings
  FOR UPDATE TO anon, authenticated
  USING (true)
  WITH CHECK (true);

-- 6. Allow admin panel to delete or permanently cancel appointments
CREATE POLICY "Allow public delete on bookings" ON bookings
  FOR DELETE TO anon, authenticated
  USING (true);
```

## 3. Admin Panel Features
- **Accessing Admin Panel:**
  - Click **"Admin Panel"** in the top bar or header of the website, or navigate directly to `#admin` or `?admin=true`.
  - Click **"Back to Public Website"** to return to the resident-facing site at any time.
- **View All Bookings:**
  - Displays all appointments stored in your Supabase database with candidate name, phone, section (Boys/Girls), sharing type, and move-in date.
- **KPI Metrics:**
  - Real-time counters for Total Inquiries, Pending Visits, Confirmed Appointments, Admitted/Visited residents, and Cancelled appointments.
  - Gender demand breakdown (Boys Wing vs Girls Wing).
- **Search & Filters:**
  - Search by resident name, phone number, room assignment, or notes.
  - Filter by Status (Pending, Confirmed, Visited, Admitted, Cancelled).
  - Filter by Wing (Boys / Girls) and Room Sharing (Single / Double / Triple).
- **Manage & Edit:**
  - Quick status dropdown right in the table.
  - Click the **Edit icon** to change resident details, assign specific room numbers (e.g. `Room 204`), or add staff follow-up notes.
- **Cancel / Delete Appointments:**
  - 1-click cancel button marks status as `cancelled`.
  - Trash icon permanently deletes test or spam entries with confirmation.
- **Direct Resident Communication:**
  - 1-click **Call** (`tel:...`)
  - 1-click **WhatsApp** with personalized greeting.
- **Walk-In Recording:**
  - Click **"Add Walk-In"** to manually enter in-person visitors or phone inquiries into your Supabase database.
- **Export CSV:**
  - Download a `.csv` spreadsheet file for offline hostel records and billing.
